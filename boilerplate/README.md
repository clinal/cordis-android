# Cordis Android plugin workspace

This workspace is based on [`cordiverse/boilerplate`](https://github.com/cordiverse/boilerplate)
and contains the `cordis-plugin-android` package in `packages/android`.

## Scripts

- `yarn dev` starts the Cordis development server and WebUI.
- `yarn start` starts Cordis from `cordis.yml`.
- `yarn build` builds all workspace packages.
