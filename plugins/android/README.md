# Cordis Android plugin workspace

Cordis boilerplate-style workspace for the `cordis-plugin-android` package.

## Scripts

- `npm run dev` starts Cordis with TypeScript and YAML loaders.
- `npm run start` starts Cordis from `cordis.yml`.
- `npm run typecheck` checks workspace packages.
- `npm run build` builds workspace packages.

The plugin package lives in `packages/android`.
